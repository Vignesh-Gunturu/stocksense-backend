# StockSense AI — Backend

Spring Boot 3.2 (Java 17) REST API with JWT auth, MySQL, and a demand-prediction engine.

## Run
1. Install JDK 17 and MySQL 8.
2. Optionally set env vars: `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`, `JWT_SECRET`, `CORS_ORIGINS`.
3. `mvn spring-boot:run`

API: http://localhost:8080 — Swagger UI: http://localhost:8080/swagger-ui.html
